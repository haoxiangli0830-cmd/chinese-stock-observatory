# 中国股票与ETF价格观察台

一个面向中国 A 股与交易所 ETF 的公开价格观察工具。网页端用于日常查询、品种管理和图表比较，Excel 报告用于离线留档与年度高低点汇总。

## 已实现功能

- 初始内置 9 家银行：招商银行、兴业银行、交通银行、工商银行、农业银行、中国银行、光大银行、建设银行、邮储银行。
- 初始内置 10 只 ETF：510300、512100、159915、588000、159920、513100、513880、513030、518880、511090。
- 按股票或 ETF 代码、中文名称搜索，经行情接口验证后才能加入观察名单。
- 公开添加、停用和恢复品种；不永久删除，并保留活动记录。
- 单品种收盘价与成交量图，可切换 1 个月、6 个月、今年以来、1 年、5 年和全部。
- 可按“全部 / A股 / ETF”筛选图表和年度表。
- 不复权与前复权切换；年度最低价和最高价始终使用不复权日线。
- 最多 5 个品种按起点归一为 100 后比较，避免价格量级不同造成误导。
- 最近 4 年年度高低点表，并可自定义起止年份。
- 新增股票或 ETF 进入后台队列并在约 30 分钟内补齐完整历史；每个交易日收盘后增量同步。
- 单股图自动标记当前时间范围内的最高价与最低价；1 年、5 年和全部视图还会标记范围内每个自然年的最高/最低点、价格和日期。
- 自选股管理在中小屏幕和浏览器缩放时切换为抽屉，避免遮挡图表。
- 网页可手动刷新当前图表。
- 可下载包含当前所有股票与 ETF 的动态 Excel 导出，并保留银行历史样本工作簿。

## 数据来源

- 股票日线历史与每日更新：[AKShare 股票数据](https://akshare.akfamily.xyz/data/stock/stock.html)，优先读取东方财富接口，异常时自动切换新浪接口
- ETF 日线历史与每日更新：[AKShare ETF 数据](https://akshare.akfamily.xyz/data/fund/fund_public.html)，读取东方财富 ETF 接口
- 股票与 ETF 搜索、代码验证：东方财富公开行情接口
- 网页图表只读取 D1 缓存，不会因访问人数增加而重复调用外部行情源
- 初次部署离线回退：随应用打包的 9 家银行 7,785 行不复权日线快照

行情按日终读取，不是实时交易报价。界面和导出会保留交易所、币种、复权方式、来源、获取时间与延迟状态。本项目仅用于信息整理和研究，不构成投资建议。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。首次访问时，D1 数据库会自动创建初始观察名单和 2023—2026 年年度区间。

验证：

```bash
npm test
npm run lint
```

## 每日自动更新

仓库中的 `.github/workflows/daily-price-refresh.yml` 包含三种任务：每 30 分钟处理待同步品种、工作日北京时间 17:30 增量更新，以及每周刷新完整前复权历史。也支持手动触发。请在 GitHub 仓库设置以下 Actions Secrets：

- `APP_BASE_URL`：已部署网站的根网址
- `SYNC_SECRET`：自定义的强随机密钥；必须与托管环境中的同名变量一致

Python 依赖：

```bash
pip install -r requirements.txt
```

同步逻辑只使用 AKShare，不需要账户、令牌或积分。单个品种失败不会中断其他品种，失败状态会写入观察台并在后续队列中自动重试。在首次计划同步完成前，九家初始银行会使用内置不复权快照；新 ETF 会显示等待同步状态，前复权按钮不会把不复权快照冒充为前复权数据。

## 数据结构

- `stocks`：股票/ETF 类型、观察名单、启用状态和同步状态
- `prices`：不复权/前复权日线
- `annual_ranges`：按自然年计算的成交最低价与最高价
- `activity_log`：添加、停用、恢复记录
- `sync_state`：最近一次计划同步状态

新增年份无需改表结构：计划任务按当前年份写入日线并重新计算当年高低点，进入下一年后旧年份自然成为历史数据。

## 技术说明

- 前端与 API：React、Next.js 兼容路由、vinext
- 图表：Recharts
- 持久化：Cloudflare D1
- 托管：OpenAI Sites / Cloudflare Workers

网站采用 D1 而不是 Supabase，原因是当前托管平台可直接提供同类的持久化 SQL 数据库，部署更少一个外部账户；公开添加、状态恢复、活动记录和年度滚动逻辑保持不变。
